# NOS-4 · CI: lint, tipos, testes e tamanho de PR

**Sprint:** S0 · **Estimativa:** 1,5 h · **Branch:** `chore/s0-ci`

## Objetivo
Toda PR roda lint, typecheck, testes e o limite de 20 arquivos, e só faz merge com tudo verde.

## Contexto
- `package.json`, `turbo.json`, `scripts/check-pr-size.sh`

## Referências (context7)
- github actions (oven-sh/setup-bun, actions/setup-node), eslint flat config, typescript-eslint, next eslint plugin, vitest

## Requisitos
- `eslint.config.mjs` na raiz (flat config) com typescript-eslint `strictTypeChecked` e o plugin do Next em `apps/web`.
- Regra que proíbe `any` explícito e `console.log` (permite `console.error`).
- `.github/workflows/ci.yml`: em `pull_request`, roda `bun ci`, `bun run lint`, `bun run typecheck`, `bun run test` e `scripts/check-pr-size.sh origin/${{ github.base_ref }}`.
- Cache do Bun (`~/.bun/install/cache`) e do Turbo.

## Fora de escopo
- E2E (Playwright) e pgTAP no CI (entram na S1 e na S6).

## Cenários (BDD)
```gherkin
Funcionalidade: Portão de qualidade na PR

  Cenário: PR com erro de tipo é bloqueada
    Dado uma PR que atribui uma string a uma variável number
    Quando o CI roda
    Então o job "typecheck" falha

  Cenário: PR com any explícito é bloqueada
    Dado uma PR com "const x: any = 1"
    Quando o CI roda
    Então o job "lint" falha citando "no-explicit-any"

  Cenário: PR grande é bloqueada
    Dado uma PR com 21 arquivos alterados
    Quando o CI roda
    Então o passo "PR size" falha

  Cenário: PR limpa passa
    Dado uma PR sem erros com 5 arquivos
    Quando o CI roda
    Então todos os jobs ficam verdes em menos de 4 minutos
```

## Critérios de aceite
- [ ] Os 4 cenários comprovados com PRs de teste (fechadas sem merge) ou descritos no PR
- [ ] A `main` exige o check "ci" para merge

## Plano de testes (TDD)
| Cenário | Tipo | Arquivo |
| --- | --- | --- |
| Erro de tipo, any, PR grande | PR de teste | `.github/workflows/ci.yml` |
| Regras de lint | unit: lint de um fixture | `tooling/eslint/fixtures/` (só se ficar simples; senão, PR de teste) |

## Limites
- Até 20 arquivos. Dependências: eslint, typescript-eslint, @next/eslint-plugin-next.
